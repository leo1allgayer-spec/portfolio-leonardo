# Portfólio Leonardo

Portfólio profissional criado no Google Stitch e publicado na Cloudflare Pages.

## Estrutura

- `index.html`: página pública responsiva.
- `stitch-source/`: exportação original do Stitch, incluindo layouts desktop e mobile.

## Publicação

O site pode ser publicado diretamente como conteúdo estático, sem etapa de build.
